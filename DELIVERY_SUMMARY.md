## 📚 Course Content Summary

### Chapters Delivered: 13/13 ✅

#### Part 1: Foundations

1. **Java Fundamentals** (~3,500 words)
   - JVM, JRE, JDK architecture
   - Compilation and bytecode execution
   - Primitive vs reference types
   - Control flow and loops
   - Arrays and basic operations

2. **Object-Oriented Java** (~3,200 words)
   - Classes, objects, constructors
   - Encapsulation and access modifiers
   - Inheritance and polymorphism
   - Interfaces and abstract classes
   - Composition vs inheritance
   - static and final keywords

3. **Modern Java** (~2,800 words)
   - Records (Java 16+)
   - Sealed classes (Java 17+)
   - Pattern matching
   - Enums with fields and methods
   - Optional for null safety
   - Switch expressions
   - Text blocks

#### Part 2: Critical Concepts

4. **equals() & hashCode()** (~3,000 words)
   - Reference vs value equality
   - The equals() contract
   - The hashCode() contract
   - HashMap internals and bucket behavior
   - Mutable key problems (deep dive)
   - Common production bugs

5. **Collections & Generics** (~3,500 words)
   - List (ArrayList vs LinkedList)
   - Set (HashSet, TreeSet, LinkedHashSet)
   - Map (HashMap, TreeMap, LinkedHashMap)
   - Generic types, bounds, wildcards
   - Comparable and Comparator
   - Immutable collections

6. **Functional Java & Streams** (~3,000 words)
   - Functional interfaces
   - Lambda expressions and method references
   - Stream API (creation, operations, collectors)
   - Practical transformation examples
   - Lazy evaluation
   - When NOT to use streams

#### Part 3: Language Features

7. **Strings** (~2,500 words)
   - Immutability and the String pool
   - == vs equals() for strings
   - String operations and transformations
   - StringBuilder for efficient building
   - String formatting and conversions

8. **Exceptions** (~2,800 words)
   - Exception hierarchy
   - Checked vs unchecked exceptions
   - Try-catch-finally and try-with-resources
   - Custom exceptions
   - Exception chaining
   - Best practices and common mistakes

9. **Java IO** (~2,200 words)
   - Reading user input (Scanner)
   - File reading and writing
   - NIO2 (modern file operations)
   - Streams (binary data)
   - Serialization
   - Formatted output

10. **JVM Fundamentals** (~2,800 words)
    - Execution pipeline (source → bytecode → native)
    - Stack vs heap memory
    - Garbage collection concepts
    - Class loading and initialization
    - JIT compilation
    - Common runtime errors

#### Part 4: Practice & Preparation

11. **Practical Exercises** (~2,500 words)
    - 6 hands-on exercises (basic to advanced)
    - Real-world scenarios
    - Complete solutions with explanations
    - Difficulty levels marked clearly

    - Production context provided

## 🚀 Deployment Instructions

### GitHub Pages Setup

1. **Create Repository**
   ```bash
   git init
   git remote add origin https://github.com/axxes/java-training.git
   ```

2. **Push to GitHub**
   ```bash
   git add .
   git commit -m "Initial Java training course"
   git push -u origin main
   ```

3. **Enable GitHub Pages**
   - Go to repository Settings
   - Navigate to Pages
   - Select "Deploy from a branch"
   - Choose `main` branch
   - Save

4. **Site Published**
   - Available at: `https://axxes.github.io/java-training/`
   - Or custom domain: Configure in Settings

### Local Development

```bash
# Install Jekyll
gem install jekyll bundler

# Run locally
jekyll serve

# Visit http://localhost:4000
```
