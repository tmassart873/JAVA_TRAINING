## Welcome to Axxes Java Training

This is a **comprehensive, professional-grade Java refresher course** designed for developers working with Java, Spring Boot, and modern backend architectures at Axxes.

### What This Course Covers

This refresher is structured around **10 core learning modules**, followed by practical exercises and interview preparation. The material is based on the foundational concepts in the Baeldung "Get Started with Java" series, but significantly expanded with:

- **Deep technical explanations** – not just syntax, but the WHY behind Java design
- **Modern Java 21 practices** – records, sealed classes, pattern matching, and more
- **Production-grade examples** – code you'd actually see in enterprise applications
- **Common mistakes** – the pitfalls developers encounter in real projects
- **Professional recommendations** – when to use something, and when NOT to
- **Interview preparation** – questions typically asked during technical interviews

### Target Audience

This course is designed for:

- **Java developers** with some professional experience
- **Consultants** working on backend systems
- **Anyone** preparing to work with Spring Boot, microservices, and modern Java
- **Developers** who need to refresh their understanding of Java fundamentals
- **Interview candidates** preparing for Java technical interviews

### How to Use This Material

1. **Start with Java Fundamentals** – even if you think you know it, the depth will surprise you
2. **Follow the learning path sequentially** – each module builds on the previous
3. **Read the Markdown chapters** – they contain deep explanations and examples
4. **Review the code examples** – try them, modify them, understand them
5. **Complete the exercises** – practical work cements learning
6. **Study the interview questions** – they reveal what you should know deeply
7. **Reference the Baeldung links** – dive deeper into topics that interest you

### Key Features

#### 🔍 **Deep Technical Content**
Not "Hello World" tutorials. Understand *why* Java works the way it does, not just *how*.

#### 🏗️ **Professional Examples**

#### 🎯 **Modern Java Focus**
Java 21 LTS is the primary reference, with explanations of Java 17 compatibility where relevant.

#### 💡 **Interview Preparation**

#### ⚠️ **Common Pitfalls**
Learn from mistakes others have made. Understand why certain patterns are dangerous.

## About This Course

### Why Java Refresher?

Java is a mature language with decades of evolution. Developers often have experience with *an* older version of Java or may have skipped over important concepts. This course ensures you understand:

1. **How Java actually works** – from source code to JVM execution
2. **Modern best practices** – Java 21 conventions and patterns
3. **The "why" behind the language** – not just syntax, but design philosophy
4. **Professional production code** – how to write robust, maintainable applications
5. **What interviewers ask** – technical depth valued in strong engineers

### Java Version

- **Primary**: Java 21 LTS (latest long-term support version)
- **Compatibility**: Java 17+ features discussed where relevant
- **Baseline**: Assumes Java 11+ knowledge, updates from there

### Learning Methodology

This course uses the **"What → Why → How → When → Common Mistake"** pattern for each topic:

1. **What is it?** – Definition and basic concept
2. **Why does it exist?** – Problem it solves
3. **How does it work?** – Implementation details
4. **When should I use it?** – Practical recommendations
5. **Common mistake** – What goes wrong in production

This approach builds understanding, not just memorization.

### Sources & Attribution

This course is based on:
- **Baeldung Java tutorials** – comprehensive practical guides
- **Oracle Java documentation** – official language specification
- **OpenJDK documentation** – implementation details
- **Professional experience** – real-world patterns and pitfalls

All sources are documented in the [References]({{ '/docs/13-references' | relative_url }}) section.
